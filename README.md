# 🚀 UDAAN — Government Exam Prep Copilot

**Single-user, local-first, AI-powered preparation for every major Indian government exam.** Rokky (your rocket mascot/coach) generates quizzes from each exam's real pattern, grades descriptive answers with board-examiner rubrics, and writes an honest, chart-packed report card after every attempt.

## ✨ What it does

| Area | Features |
|---|---|
| **Exam intelligence** | 14 exams mapped (UPSC CSE, SSC CGL/CHSL, IBPS PO, SBI PO, RBI Grade B, NDA, CDS, AFCAT, RRB NTPC, RRB Group D, MPPSC, UGC NET, CTET) — official patterns, per-section marks/timers, negative marking, syllabus with PYQ-frequency & difficulty tags, trends, PYQ-style sample questions, study-plan templates |
| **AI exam generation** | Topic quizzes, pattern-authentic mini mocks (sectional timers, scaled marks), mains-style descriptive papers — generated by the agentic system below |
| **Agentic system** | Master model (`gemini-flash-latest`) handles hard tasks (scoring, reports, plans, digests, validation); slave model (`gemini-flash-lite-latest`) handles light tasks (quiz drafts, outlines, flashcards, explanations) — serial FIFO lanes with queue+wait pipelines |
| **Key management** | Multiple Gemini API keys, round-robin / failover rotation, per-(key × model) RPM token buckets (defaults 5/15/30 RPM — tunable), 429 backoff, quota cooldown, automatic model fallback chains |
| **Quiz engine** | Negative-marking-aware scoring, section timers with locks, mark-for-review palette, guess audit (<8s answers), offline sample-question fallback (works with no key) |
| **Descriptive mode** | Mains-style papers; AI rubric scoring (content/structure/examples/language), band scores, model answers |
| **Report cards** | Predesigned markdown templates rendered with **marked.js** + hand-built SVG charts (donut/bar/radar/sparkline); the LLM only fills the data. Honest reality checks, guess-damage analysis, action plans. Print → PDF |
| **Analytics** | Per-exam readiness (adaptive EWMA + forgetting-curve decay + confidence), strong/weak/developing topic classification, weighted recommendations, score trends, per-type accuracy, streak & heatmap |
| **Study** | Streaming AI summaries (concise/detailed/ELI5), scroll progress, reading library, AI study plans built around your measured weak topics |
| **Revision** | Flashcards with SM-2-lite spaced repetition, one-click deck generation from your wrong answers |
| **Daily digest** | Exam-aware current-affairs digest with Google Search grounding + self-test MCQs |
| **3D UX** | Scroll-panned 3D hero (rocket takeoff), tilt cards, glassmorphism, Rokky's personality throughout |

## 🛠 Quick start

```bash
npm install
npm run dev          # http://localhost:3000
```

1. Complete the one-time onboarding (name, target exam, exam date).
2. **Settings → Models & Keys** → paste a Gemini API key (ai.google.dev). It's verified live and stored only in the gitignored `./data` folder. *(Optionally: `GEMINI_API_KEY=... node scripts/seed.mjs` to seed a key from the environment.)*
3. Practice → generate a quiz, or Mocks → build a pattern-authentic mini mock. Every submission produces a report card and updates your mastery map.
4. Without any key the app still works offline using bundled PYQ-style sample questions.

## ⚠️ Honest notes

- **Exam pattern data** was verified against 2025–26 notifications/analyses on 2026-08-13 (sources in `docs/RESEARCH.md`). Where sources conflicted (e.g., MPPSC negative marking), both positions are encoded with notes. Always re-verify with official notifications before the actual exam.
- **Mini mocks** scale the real pattern proportionally (AI can't reliably generate a 100-question paper in one call) — structure, timers and negative marking stay authentic.
- **Model availability varies by account**: on newer Gemini accounts the `gemini-flash-latest` alias can hang and `gemini-2.5-flash` returns 404. The orchestrator probes models, marks dead ones, and falls back (`gemini-3-flash-preview` → `gemini-flash-lite-latest` → `gemini-3.5-flash` for master). Pick whatever works for your key in Settings.
- All data lives in `./data/db.json` (gitignored). Export backups from Settings → Data.
